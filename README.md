# Roblox Game Lobby

This project contains scripts for a Roblox game lobby inspired by the Bungo Stray Dogs anime's main office. It includes scripts for the lobby environment, player spawning, NPCs, and player interactions.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio.
3. Create a new Roblox game or open an existing one.
4. Place the `lobby_script.lua` in the Workspace.
5. Place the `player_spawn_script.lua` in the StarterPlayerScripts.
6. Place the `npc_script.lua` in the Workspace.
7. Place the `interaction_script.lua` in the StarterPlayerScripts.

## Use

1. Open your Roblox game in Roblox Studio.
2. Run the game to see the lobby environment.
3. Players will spawn in the lobby as defined in the `player_spawn_script.lua`.
4. NPCs will be present in the lobby as defined in the `npc_script.lua`.
5. Players can interact with objects in the lobby as defined in the `interaction_script.lua`.
